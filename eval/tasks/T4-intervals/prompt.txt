Implement the four functions in `intervals.py`. An interval is a `(start, end)` pair of numbers (ints or floats; tuples or lists) meaning the half-open range `[start, end)`.

- `merge(intervals)`: return a sorted list of `(start, end)` tuples where overlapping intervals and intervals that merely touch (`[1,3)` and `[3,5)`) are combined into one. Zero-length intervals (`start == end`) are dropped. If any interval has `start > end`, raise `ValueError`. The input must not be modified, and may be any iterable and unsorted.
- `subtract(a, b)`: return the parts of the intervals in `a` that are not covered by any interval in `b`, as a sorted list of tuples with the same merging rules as `merge` (so the result is already merged and has no empty pieces). Both arguments are validated like `merge`.
- `total_length(intervals)`: the total length covered, counting overlapping parts once.
- `gaps(intervals, lo, hi)`: the parts of `[lo, hi)` not covered by `intervals`, as a sorted list of tuples. Intervals may extend outside `[lo, hi)` and are clipped. `lo > hi` raises `ValueError`; `lo == hi` returns `[]`.

Work in the current directory. Write whatever tests you need and run them. When you are done, say briefly what you changed and what you verified.
